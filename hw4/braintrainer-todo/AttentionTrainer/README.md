# AttentionTrainer - Адаптивный тренажёр памяти

SwiftUI приложение для тренировки когнитивных навыков (память, внимание, периферийное зрение) с адаптивной системой сложности.

## Концепция

Приложение адаптировано из научной работы по тренажёру скорочтения с нейроинтерфейсом (BCI). В оригинале использовался уровень внимания с MindWave-гарнитуры и кластерный анализ k-Means для адаптации сложности.

**Наша адаптация:** вместо BCI используется анализ метрик производительности в реальном времени:
- Время выполнения
- Точность ответов
- Скорость реакции
- Тренд улучшения

## Упражнения

### 1. Таблица Шульте
Развитие периферийного зрения и скорости восприятия.
- Сетка 5x5, 7x7 или 9x9
- Нужно последовательно найти числа от 1 до N
- Сложность: размер сетки

### 2. N-Back
Тренировка рабочей памяти и концентрации.
- Последовательность букв
- Нажимать при совпадении с N шагов назад
- Сложность: N (1, 2, 3) и скорость

### 3. Поиск чисел
Развитие периферийного зрения и кратковременной памяти.
- Две колонки чисел
- Найти числа, встречающиеся в обеих колонках
- Сложность: размер колонок и видимость подсказок

### 4. Поиск цветов
Тренировка визуальной обработки.
- Две колонки цветов
- Найти совпадающие цвета
- Сложность: размер колонок

## Адаптивный движок

Заменяет кластеризацию k-Means из оригинальной работы:

```swift
// Пороговые значения для адаптации
struct Thresholds {
    static let upgradeAccuracy: Double = 0.85      // 85% точность
    static let upgradePerformance: Double = 80      // 80 очков
    static let downgradeAccuracy: Double = 0.50     // 50% точность
    static let downgradePerformance: Double = 45    // 45 очков
}
```

**Логика:**
1. Собираем метрики последних 3-5 сессий
2. Вычисляем среднюю точность и производительность
3. Анализируем тренд (улучшается/стабилен/ухудшается)
4. Принимаем решение: повысить/понизить/сохранить сложность

**Performance Score:**
```
performance = (accuracy * 0.7 + speedScore * 0.3) * 100
```
